# Self-hosted typography
These unchanged WOFF2 files were emitted by the successful Next.js build using Source Sans 3, DM Sans and Cormorant Garamond. All14 files byte-match the verified production-base10786566 build. Their content-hash filenames are retained.
The font-face declarations preserve weights, normal style, unicode ranges, swap display and exact fallback metrics. The same three Latin files are preloaded. No runtime or build-time Google font request is required.
